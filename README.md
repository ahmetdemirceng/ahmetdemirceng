### 🔥 Projects

**☁️ DevOps & Infrastructure**

- 🐳 **WordPress Stack on Docker & Kubernetes (Helm):** Built a custom Docker image (public on Docker Hub) and a 3-service Docker Compose stack (Nginx, WordPress, MySQL) with network isolation, healthchecks and Docker Secrets. Configured HTTPS/TLS with a self-generated Root CA (OpenSSL), migrated the stack to Kubernetes (Deployment, Service, ConfigMap, Secret, PVC, Ingress) and reduced a 9-step manual deployment to a single command with a parametric Helm chart. *(Internship project at TEI)*

**⚡ High-Performance & Simulation**

- 🚀 **High-Performance C++20 Simulation Engine:** Kinematic simulation infrastructure that compares object-oriented and data-oriented (ECS) designs. Moving the data layout from AoS to SoA/AoSoA with AVX2 vectorization gave 1.3–2.1x faster runs; profiled with Intel VTune and Linux perf and parallelized with OpenMP and CUDA. *(Internship project at TÜBİTAK SAGE)*
- 🚗 **Autonomous Vehicle Simulation (.NET, WinForms):** 2D desktop simulation of vehicle dynamics and collision avoidance, with event-based decision matrices and obstacle-avoidance algorithms driven by virtual sensor data.

**🌐 Web & Backend**

- 🏋️ [**Gym Management System**](https://github.com/ahmetdemirceng/GymManagementSystem): Stateless RESTful API in C# and ASP.NET Core with a relational SQL database, CRUD operations and business-logic layers.
- 📅 [**Art & Studio Reservation System**](https://github.com/ahmetdemirceng/Art-And-Studio-Reservation-System): Reservation management for studio and workshop appointments (C#, .NET), including conflict checking, time-slot planning and user registration logic.
- 📈 [**IPO Tracking Web Platform (Halka-Arz)**](https://github.com/ahmetdemirceng/Halka-Arz): Dynamic web platform presenting current IPO data, company financial details and distribution information, with data filtering, listing and responsive front-end components (TypeScript).
- 🔐 [**Secure Messaging System**](https://github.com/ahmetdemirceng/GuvenliMesajlasma): Multi-threaded real-time client-server messaging in C# over TCP/IP sockets, using DES/AES symmetric encryption to reduce man-in-the-middle risks.

**📱 Mobile & Embedded**

- 🤖 [**AsistanApp**](https://github.com/ahmetdemirceng/AsistanApp): Cross-platform React Native app that analyzes a user's daily mood using an external AI API.
- 🚄 **Hyperloop Embedded Software & Control:** Onboard telemetry, sensor reading and control software on Raspberry Pi and Arduino, plus a Flutter control panel for live vehicle monitoring and sending commands (team project, TEKNOFEST 1st place).
- 🏢 [**Elevator Control System (VHDL)**](https://github.com/ahmetdemirceng/Elevator-Control-System): 4-floor elevator controller modeled as a finite state machine (FSM), covering cabin movement, floor calls, door control and call prioritization.

**🧱 Core Programming**

- 🍔 [**ReYeTaP – Restaurant Food Tracking System (C)**](https://github.com/ahmetdemirceng/ReYeTaP-RestoranYemekTakipProjesi): Terminal-based console app where customers place orders and restaurant management tracks the process, built to apply pointers and memory management.
- ✅ [**To-Do List (Python)**](https://github.com/ahmetdemirceng/To-Do-List): Console task manager with JSON-based persistent storage, CRUD operations, priorities, due dates (datetime) and try-except error handling.
